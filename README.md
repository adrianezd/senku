# Senku

El solitario de clavijas de toda la vida: salta bolas en línea recta hasta dejar solo una. Tablero inglés (33), europeo (37) y triangular (15), con deshacer, pistas que buscan un salto ganador y récords por tablero.

🔗 **Jugar ahora:** https://adrianezd.github.io/senku/

Sitio estático sin dependencias ni build (HTML, CSS y JavaScript vanilla) servido por GitHub Pages. Funciona sin conexión gracias a `sw.js`. Los récords se guardan solo en tu navegador (`localStorage`).
